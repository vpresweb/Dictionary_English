# Dictionary_English

Интерактивный англо-русский словарь, работает через web. Сделан по образцу
[Dicionário Português](https://github.com/vpresweb/Dicionario_Portugues).

## Возможности

- поиск в обе стороны: EN → RU и RU → EN;
- более 10 000 слов и выражений уровня A1–B2 по тем же темам, что и в португальском словаре: люди и характер, тело и медицина, дом и быт, еда, одежда и деньги, город и путешествия, работа, учёба, наука и ИТ, природа, общество и право, СМИ, досуг, спорт и искусство, документы, страны и национальности, глаголы (в том числе фразовые), прилагательные, наречия, служебные слова, идиомы и выражения;
- формы глаголов: Past Simple, Past Participle, -ing и 3-е лицо (he / she / it), отметка «правильный / неправильный»;
- неправильное множественное число (`child` → `children`) и степени сравнения (`good` → `better`, `best`);
- поиск по формам (`went` найдёт `go`, `teeth` — `tooth`), приставку `to` можно не убирать (`to go`);
- подсказки при опечатке (`brougth` → «Возможно, вы имели в виду: brought (bring)»);
- ссылка на результат поиска (`?q=слово`);
- режим карточек для заучивания слов (`#cards`);
- тест на формы глаголов (`#quiz`);
- озвучивание: нажатие на любое английское слово, форму или пример произносит его (британский голос, если есть).

Онлайн: https://vpresweb.github.io/Dictionary_English/

```

```

## Формат статьи

```json
{
  "word": "child",
  "pos": "noun",
  "translations": ["ребёнок"],
  "forms": { "plural": "children" },
  "examples": [{ "en": "They have three children.", "ru": "У них трое детей." }]
}
```

`pos`: `noun`, `verb`, `adj`, `adv`, `prep`, `pron`, `det`, `conj`, `interj`, `num`, `phrase`.
`forms` и `examples` необязательны. В `forms` задаются только неправильные формы:
`plural` у существительных, `comparative` и `superlative` у прилагательных и наречий.

## Формы глаголов

Формы правильных глаголов строятся автоматически по правилам британской орфографии:
`work` → `worked`, `working`, `works`; `live` → `lived`, `living`; `study` → `studied`, `studies`;
`stop` → `stopped`, `stopping`. Удвоение конечной согласной у односложных слов делается само,
многосложным с ударением на последнем слоге и словам на `-l` нужен флаг `"double": true`
(`prefer` → `preferred`, `travel` → `travelled`).

У неправильных глаголов в `forms` задаются отличающиеся формы, варианты пишутся через `/`:

```json
{ "word": "learn", "pos": "verb", "translations": ["учить"], "forms": { "past": "learnt/learned", "participle": "learnt/learned" } }
```

Ключи: `past`, `participle` (если не задан — совпадает с `past`), `ing`, `third`. Глагол помечается
как «неправильный», если у него задан `past` или `participle`. У фразовых глаголов (`get up`, `look for`)
меняется только первое слово.

## Карточки

Вкладка «Карточки» показывает слово, по нажатию — перевод, отметки и пример. Каждое нажатие на карточку
произносит английское слово. Ответ «Знаю» или «Не знаю» можно дать сразу, не переворачивая карточку
(клавиши → и ←, пробел — перевернуть). Повторение по системе Лейтнера: пять уровней, незнакомые слова
выпадают чаще, слово считается выученным с четвёртого уровня. Можно выбрать направление (EN → RU, RU → EN)
и часть речи. Прогресс и настройки хранятся в `localStorage` браузера.

## Тест на формы глаголов

Вкладка «Тест» показывает глагол и форму (например, `go · Past Simple`) — нужно ввести её.
Если у формы несколько вариантов (`learnt/learned`), засчитывается любой. Правильный ответ озвучивается,
ниже — счёт и серия верных ответов. В настройках выбираются формы, набор глаголов (неправильные,
правильные, все) и фразовые глаголы.

## Озвучивание

Используется встроенный синтез речи браузера (Web Speech API), без внешних сервисов. Голос выбирается
в порядке en-GB → en-US → любой английский. Если английского голоса в системе нет, внизу страницы
появляется подсказка.

## Запуск

Приложение статическое, сборка не нужна. Словарь загружается через `fetch`, поэтому страницу нужно открывать через локальный сервер, а не как файл:

```
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Тесты

Автотесты используют встроенный в Node.js (20+) модуль `node:test`, зависимостей нет:

```
npm test
```

Проверяются правила построения форм, целостность `data/dictionary.json`, эталонные формы неправильных
глаголов, поиск, подсказки и логика теста. Тесты запускаются в GitHub Actions при каждом push в `main`.
